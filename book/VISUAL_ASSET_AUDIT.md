# BẢN KIỂM TOÁN TÀI NGUYÊN HÌNH ẢNH TOÀN SÁCH (VISUAL ASSET AUDIT)

Tài liệu này ghi nhận kết quả kiểm toán toàn diện 100% các sơ đồ, hình ảnh kỹ thuật trong toàn bộ cuốn sách Go Living Textbook.

Nguyên tắc xử lý:
1. **Source of Truth:** Mọi sơ đồ phải có file source văn bản (`.puml` hoặc code vector). File `.png` chỉ là artifact biên dịch.
2. **Vietnamese Visual Prose ≈ 99%:** Dịch toàn bộ các nhãn giải thích cho người đọc sang tiếng Việt trong sáng, tự nhiên; giữ nguyên 100% các định danh kỹ thuật mã nguồn (Go keywords, package names, API symbols, CLI commands).
3. **No Hallucination:** Không vẽ quan hệ/mũi tên nếu không có bằng chứng kỹ thuật.
4. **Action Taxonomy:** Mỗi asset chỉ được gán một trong 6 hành động: `TRANSLATE_SOURCE`, `REDRAW_PLANTUML`, `CONVERT_TO_BUZAN_MINDMAP`, `KEEP_EXACT_EVIDENCE`, `REPLACE_WITH_BETTER_VISUAL`, `REMOVE`.

- **REMOVE:** 0 (tất cả 30 assets đều có giá trị sư phạm thực chất).
