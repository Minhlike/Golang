# Fonts được nhúng trong PDF

PDF nhúng font để mở giống nhau trên máy khác và không phụ thuộc font Windows.

| Font | Bản | Vai trò | License và nguồn |
| --- | --- | --- | --- |
| Source Serif 4 | 4.005 | Thân bài và bảng | SIL Open Font License 1.1; https://github.com/adobe-fonts/source-serif/releases/tag/4.005R |
| Source Sans 3 | 3.052 | Title, heading, metadata | SIL Open Font License 1.1; https://github.com/adobe-fonts/source-sans/releases/tag/3.052R |
| JetBrains Mono | 2.304 | Code block và inline code | SIL Open Font License 1.1; https://github.com/JetBrains/JetBrainsMono/releases/tag/v2.304 |

Các binary font này được đưa vào repository vì license cho phép phân phối lại.
